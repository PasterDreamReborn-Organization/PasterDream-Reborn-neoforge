## 登记规则

- 每次同步开工与收尾各查一次上游 `master` 与开放 PR；只同步已合并 PR 的净差异，未合并 PR 只作影响预警。
- 同步完成并通过 `runData`、`build`（运行时行为按需 `runGameTestServer`）后，在「同步登记」表追加一行，并把「当前游标」改成该行 PR。
- 表中只写 PR 编号、合并提交、日期和验证结论；不写实现内容、影响模块、来源清单或逐文件对照。
- 游标表示「已同步到哪个 PR」，不代表更早的历史内容都已移植；客户端画面、真实世界生成与多人行为由用户验收，未验收项在验证列标「待用户验收」。
- 一次同步覆盖多个 PR 时按合并顺序分行登记，或合并为一行并在 PR 列列出全部编号。
