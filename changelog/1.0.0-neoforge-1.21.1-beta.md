# 更新日志

## v1.0.0-neoforge-1.21.1-beta（NeoForge 1.21.1）

版本号：`1.0.0-neoforge-1.21.1-beta`

> 本版基于 `v1.0.0-neoforge-1.21.1-alpha`，汇总其后的修复、内容调整与技术改动；上游同步只推进上游同步记录中的 PR 游标，同步细节不在此重复。

### 新增

- 添加「创造模式解锁《旧梦归引》全部词条」配置项，默认开启

### 调整

- 调整《旧梦归引》的「料理」条目为两页，补充饱腹时仍可进食、饱食度已满时吃下的食物会先转为生命值、生命值已满再转为黄心、黄心上限随料理等级提高、效果结束或降级后黄心仍保留等说明
- 调整《旧梦归引》的「振奋」「不振」「恍惚」条目，将效果描述中的「技能冷却时间」改为「战技冷却缩减」
- 调整《旧梦归引》的「寻梦者笔记」条目，补充笔记有成文与碎片两种形态，碎片可从遗迹与敌人身上搜刮

### 修复

- 修复重新进入存档后已装备的饰品掉回背包的问题
- 修复染梦树叶与世界树树叶破坏时不掉落染梦树苗的问题
- 修复进入染梦维度后「染梦珍藏」进度无法获取的问题
- 修复首次加入世界时未发放《旧梦归引》指南书的问题，补上搬运时遗漏的发放逻辑，已领取过的玩家不会重复获得，背包已满时改为掉落在脚下
- 修复缺少「首次加入世界时发放《旧梦归引》」配置项的问题，补上搬运时遗漏的配置，默认开启
- 修复风之旅途的风泊群岛与迷梦云层群系名称未翻译的问题
- 修复融梦涌泉与熔融阴影方块名称未翻译的问题
- 修复秋麒麟茶与染梦香水名称未翻译的问题
- 修复升级套件未显示提示文本的问题
- 修复未解析的笔记未显示提示文本的问题
- 修复「复制」与「研究」配方分类名称未翻译的问题
- 修复休憩、振奋、不振、恍惚、疯狂、混乱、美梦祈愿、料理、暗影沉默与束缚十个状态图标物品的名称未翻译的问题
- 修复融梦水晶与撼地水晶的名称未翻译的问题
- 修复盆栽方块名称未翻译的问题
- 修复风行者披风展开时的字幕未翻译的问题
- 修复进度描述中「草薙」误写为「草雍」的问题
- 修复语言文本中省略号与全角括号写法不统一的问题
- 修复「融梦涌泉」流体在英文文本中的拼写错误
- 修复染梦藤蔓的可攀爬标签

### 技术

- 添加语言文件校验脚本，检查键重复、占位符、省略号与全角括号写法，并接入构建的 checkLang 与 check 任务
- 添加语言文件校验的 GitHub Actions 工作流，在提交与拉取请求时自动检查中英文语言文件
- 统一饰品单件装备的判断逻辑到饰品装备辅助类，供全部饰品复用
- 调整树叶掉落表的构造方式，树苗沿用原版掉率，果实单独成池
- 为《旧梦归引》发放、染梦藤蔓攀爬与染梦珍藏进度补充 GameTest
- 更新程序规范与工具提示文档，补充第三方类 Mixin 的配置约定
- 更新饰品与内容移植的开发技能文档
