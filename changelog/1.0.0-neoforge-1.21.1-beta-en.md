# Changelog

## v1.0.0-neoforge-1.21.1-beta (NeoForge 1.21.1)

Version: `1.0.0-neoforge-1.21.1-beta`

> This release builds on `v1.0.0-neoforge-1.21.1-alpha` and collects the fixes, content adjustments, and technical changes that followed it. Upstream syncing only advances the PR cursor in the upstream sync record, so the synced details are not repeated here.

### Added

- Added an "unlock all Seniors' Dream Guide entries in Creative mode" config option, enabled by default

### Changed

- Expanded the "Cook" entry of the Seniors' Dream Guide to two pages, adding notes that you can keep eating while full, that food eaten at a full hunger bar first refills health and then becomes yellow absorption hearts, that the absorption cap rises with the effect's level, and that absorption hearts remain when the effect ends or is downgraded
- Changed the effect description of the "Cheer Up", "Lethargy", and "Trance" entries in the Seniors' Dream Guide from "skill cooldown" to "skill cooldown reduction"
- Expanded the "Dreamseeker Notes" entry of the Seniors' Dream Guide to mention that notes exist both as complete texts and as fragments, and that fragments can be scavenged from ruins and enemies

### Fixed

- Fixed equipped curios dropping back into the inventory after reloading a save
- Fixed Dyedream Leaves and Dyedream Worldtree Leaves not dropping Dyedream Saplings when broken
- Fixed the "Dyedream Collection" advancement not being granted after entering the Dyedream dimension
- Fixed the Seniors' Dream Guide not being given when first joining a world, restoring the distribution logic missed during the port: players who already received it are not given another, and it drops at the player's feet when the inventory is full
- Fixed the missing "give the Seniors' Dream Guide on first world join" config option, restoring the setting missed during the port, enabled by default
- Fixed the Wind Moor Archipelago and Misty Dream Cloud Layer biome names being untranslated
- Fixed the Melt Dream Liquid and Shadow Liquid block names being untranslated
- Fixed the Goldenrod Tea and Dyedream Perfume names being untranslated
- Fixed Upgrade Kits not showing their tooltip
- Fixed unknown notes not showing their tooltip
- Fixed the "Copy" and "Research" recipe category names being untranslated
- Fixed the names of the ten status icon items (Rest, Cheer Up, Lethargy, Trance, Madness, Chaos, Dream Wish, Cuisine, Shadow Silence, and Bind) being untranslated
- Fixed the Melt Dream Crystal and Shaking Crystal entity names being untranslated
- Fixed the potted plant block names being untranslated
- Fixed the subtitle for the Windrunner Cloak unfolding being untranslated
- Fixed "Kusanagi" being misspelled in advancement descriptions
- Fixed inconsistent ellipses and full-width parentheses in language texts
- Fixed the English spelling of the Melt Dream Spring fluid
- Fixed the Dyedream Vine's climbable tag

### Technical

- Added a language file check script that validates duplicate keys, placeholders, ellipses, and full-width parentheses, and wired it into the build's checkLang and check tasks
- Added a GitHub Actions workflow that checks the Chinese and English language files on push and pull request
- Unified the single-copy curio check into a curio equip helper reused by every curio
- Restructured the leaf loot tables so saplings keep the vanilla drop chance and fruit is generated in a separate pool
- Added GameTests for Seniors' Dream Guide distribution, Dyedream Vine climbing, and the Dyedream Collection advancement
- Updated the programming rules and tooltip documents with conventions for configuring Mixins of third-party classes
- Updated the curio and content-porting development skill documents
